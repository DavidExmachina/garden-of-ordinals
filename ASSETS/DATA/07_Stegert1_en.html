Definition

  Stegert's First \( \Psi \) refers to an ordinal collapsing function proposed by Jan-Carl Stegert in 2010[1].

  Since Rathjen's Capital \( \Psi \) is denoted as \( \Psi_\alpha^\beta(\gamma) \), which also uses the letter \( \Psi \), this OCF is denoted as \( \mathfrak{p}_\mathbb{X}^\alpha \) in the Calculate menu and the Explore menu for distinction. You can restore it by Options > Function Specification > \( \Psi_\mathbb{X}^\alpha \).

  The whole ordinal system consists of 3 functions: \( \varphi_\alpha(\beta) \), \( \alpha^+ \), and \( \Psi_\mathbb{X}^\alpha \) and the \( \Pi_0^2 \)-indescribable cardinal \( \Xi \) and they're described and defined as follows.

The Function \( \varphi_\alpha(\beta) \)

  \( \varphi_\alpha(\beta) \) denotes Veblen Function. It's defined as follows, as shown in the Help menu in the "Veblen Function" interface:

  01. \( \varphi_0(\beta)=\omega^\beta \)

  02. For a nonzero ordinal \( \alpha \), \( \varphi_{\alpha}(\beta) \) returns the \( (1+\beta) \)-th common fixed point of all the functions \( \gamma\mapsto\varphi_{\alpha'}(\gamma) \) for \( \alpha'<\alpha \).

The Function \( \alpha^+ \)

  \( \alpha^+ \) denotes the cardinal succession of \( \alpha \), which returns the least cardinal greater than \( \alpha \). For example: \( \omega^+=\Omega \), \( \Omega^+=\Omega_2 \), \( {\Omega_2}^+=\Omega_3 \) and so on.

The Function \( \Psi_\mathbb{X}^\alpha \)

  \( \Psi_\mathbb{X}^\alpha \) denotes the collapsing function, which is the core of this ordinal system. Unlike other OCFs, this OCF takes an ordinal and an exotic mathematical object called "Reflection Instance" as input. Due to the complexity of Reflection Instances and Reflection Configurations, the definition of this function is extremely complicated, making it one of the hardest OCFs to understand.

  \( \Psi_\mathbb{X}^\alpha \) returns the least element of the set \( \mathfrak{M}_\mathbb{X}^\alpha \), which contains ordinals \( \kappa \) satisfying conditions including but not limited to the following, depending on the Reflection Instance \( \mathbb{X} \):

  1. \( \kappa<i(\mathbb{X}) \), where the notation \( i(\mathbb{X}) \) will be defined later.

  2. \( \kappa\in \) some set (sometimes).

  3. \( C(\alpha,\kappa)\cap i(\mathbb{X})=\kappa \), where the set \( C(\alpha,\beta) \) will be defined later.

  4. \( \mathbb{X},\alpha\in C(\kappa) \), where \( C(\kappa)=\{\alpha|\alpha\in C(\alpha,\kappa)\} \) and the notation \( \mathbb{X}\in C(\alpha,\beta) \) will be defined later.

The Set \( C(\alpha,\beta) \)

  The set \( C(\alpha,\beta) \), which is called "The \( \alpha \)-th Skolem closure of \( \beta \)" in the paper, is defined as follows:

  \( \begin{align} C_0(\alpha,\beta) := & \beta\cup\{0,\Xi\} \\ C_{n+1}(\alpha,\beta) := & \{\gamma|\gamma=\gamma_0+\gamma_1\land\gamma_0,\gamma_1\in C_n(\alpha,\beta)\} \\ \cup & \{\gamma|\gamma=\varphi_{\alpha'}(\beta')\land\alpha',\beta'\in C_n(\alpha,\beta)\} \\ \cup & \{\gamma|\gamma={\alpha'}^+\land\alpha'\in C_n(\alpha,\beta)\cap Card\cap\Xi\} \\ \cup & \{\gamma|\gamma=\Psi_\mathbb{X}^{\alpha'}\land\alpha'\in C_n(\alpha,\beta)\cap\alpha\} \\ C(\alpha,\beta) := & \bigcup_{n<\omega}{C_n(\alpha,\beta)}=C_0(\alpha,\beta)\cup C_1(\alpha,\beta)\cup C_2(\alpha,\beta)\cup\cdots\cup C_m(\alpha,\beta)\cup\cdots \end{align} \)

  Where \( Card \) denotes the class of cardinals, including \( \omega=\varphi_0(1)=\varphi_0(\varphi_0(0)) \), and \( \mathbb{X} \) in the definition should be well-defined.

Reflection Instances and Configurations

  Reflection Instances \( \mathbb{X} \) are a mathematical object exclusively used in this OCF. They consist of 5 elements and in the form \( (\pi;(M_{\mathbb{M}(\vec{v})}^\xi-)P_m;\vec{R};\mathbb{Z};\alpha) \). Simply put:

  The 1st element \( \pi \) denotes the uncountable regular cardinal used to define this reflection instance. We define that \( i(\mathbb{X})=\pi \).

  The 2nd element \( P_m \) or \( M_{\mathbb{M}(\vec{v})}^\xi-P_m \) and the 3rd element \( \vec{R} \) denotes the characteristics of the ordinals contained in the set \( \mathfrak{M}_\mathbb{X}^\beta \).

  The 4th element \( \mathbb{Z} \) denotes the reflection instance used in the first element \( \pi \). If \( \pi \) is not in the form \( \Psi_\mathbb{Z}^\delta \), it's \( \epsilon \), which denotes "null" or "empty". Note that it's different from the \( \varepsilon \) that is used to denote "Epsilon Numbers".

  The 5th element \( \alpha \) denotes the lower bound of the ordinals that can be used in the OCF when the whole reflection instance is plugged into the OCF. For example, if \( \alpha=\omega \), then \( \Psi_\mathbb{X}^9 \) is undefined because \( 9 \) is less than \( \omega \). While \( \Psi_\mathbb{X}^\omega \) is well-defined since \( \omega \) is the least ordinal that can be used in this case. We define that \( o(\mathbb{X})=\alpha \).


  Reflection Configurations are functions of Reflection Instances that take ordinals as input. Each Reflection Configuration is uniquely defined with an uncountable regular cardinal. The quantity of variables it uses and its domain depends on the uncountable regular cardinal of this Reflection Configuration. Sometimes it can take no ordinals as input and only return one Reflection Instance.

  The complete form of the Reflection Instances and Configurations in the paper is quite complicated and tedious when written out completely. If we encounter ordinals obtained by collapsing a cardinal many times, due to the 4th element \( \mathbb{Z} \), the complete from will take exponentially more symbols to write down since we have to write down the 4th element \( \mathbb{Z} \) twice, and it doubles each time we collapse the cardinal.

  Therefore, we introduce the "Reflection Bracket Notation", which denotes the Reflection Instance \( \mathbb{G}(\alpha_0,\alpha_1,\cdots,\alpha_n) \) as \( [i(\mathbb{G}),\alpha_0,\alpha_1,\cdots,\alpha_n] \) and the Reflection Configuration \( \mathbb{G} \) as \( [i(\mathbb{G}),\cdots] \). If the Reflection Configuration \( \mathbb{G} \) has no variables, then we can write the only Reflection Instance it returns as \( [i(\mathbb{G}),] \), with a comma in the end that avoids the confusion with the "Indescribable Bracket Notation" introduced here later. We define \( \mathbb{X}\in C(\alpha,\beta) \) as \( \kappa,\alpha_0,\alpha_1,\cdots,\alpha_n\in C(\alpha,\beta) \) for \( \mathbb{X}=[\kappa,\alpha_0,\alpha_1,\cdots,\alpha_n] \).

  The 3rd element \( \vec{R} \) is an array of mathematical objects called "M-P-Expressions", which are in the form \( M_\mathbb{F}^{<\alpha}-P_n \) and they indicate that the elements in the set \( \mathfrak{M}_\mathbb{X}^\beta \) are also \( \mathfrak{M}_{[i(\mathbb{F}),\alpha_0,\alpha_1,\cdots,\alpha_n]}^\gamma \)-\( \Pi_n^1 \)-indescribable for all \( \gamma<\alpha \) and \( \alpha_0,\alpha_1,\cdots,\alpha_n \) that makes the set \( \mathfrak{M}_{[i(\mathbb{F}),\alpha_0,\alpha_1,\cdots,\alpha_n]}^\gamma \) well-defined. If \( \gamma=o(\mathbb{F}) \), then the aforementioned elements should be \( \Pi_n^1 \)-indescribable instead. The element can also have no M-P-Expressions at all, in which case it's also denoted as \( \epsilon \).

  The definition of each Reflection Configuration and therefore each Reflection Instance is extremely complicated. For the full definition, check out the "Reflection" section.

\( \mathfrak{M} \)-\( \Pi_n^1 \)-Indescribable Cardinals

  \( \mathfrak{M} \)-\( \Pi_n^1 \)-Indescribable Cardinals are cardinals that are frequently used in this OCF, which is defined as follows:

  For a class of ordinals \( \mathfrak{M} \), a cardinal \( \kappa \) is \( \mathfrak{M} \)-\( \Pi_n^1 \)-indescribable (Or \( \Pi_n^1 \)-indescribable in \( \mathfrak{M} \)) if whenever \( U_1,\cdots,U_m\subseteq V_\kappa \) and \( F \) is a \( \Pi_n^1 \) sentence of the language of \( \langle V_\kappa,\in,U_1,\cdots,U_m\rangle \) such that:

  If \( \langle V_\kappa,\in,U_1,\cdots,U_m\rangle\vDash F \), then there exists a nonzero ordinal \( \alpha\in\mathfrak{M} \) less than \( \kappa \) such that \( \langle V_\alpha,\in,U_1\cap V_\alpha,\cdots,U_m\cap V_\alpha\rangle\vDash F \).


  If we omit \( \mathfrak{M} \), then it's identical to the definition in the help article of Rathjen's Capital \( \Psi \), which means \( \mathfrak{M} \)-\( \Pi_n^1 \)-indescribability implies \( \Pi_n^1 \)-indescribability.

  As a result, a cardinal can be \( \Pi_n^1 \)-indescribable on a class of ordinals rathen than just \( \Pi_n^1 \)-indescribable. Consequently, we can create all sorts of complicated indescribable cardinals. To denote these cardinals easily, a notation called "Indescribable Bracket Notation" is defined on this website. You can check out the main help article for the complete definition. For example:

  \( [P_0] \) denotes the least \( \Pi_0^1 \)-indescribable cardinal, which is also the least Strongly Inaccessible Cardinal[2].

  \( [P_0-P_0] \) denotes the least \( \{\kappa|\kappa\) is \( \Pi_0^1 \)-indescribable\(\} \)-\( \Pi_0^1 \)-indescribable cardinal, or the least \( \Pi_0^1 \)-indescribable-\( \Pi_0^1 \)-indescribable cardinal.

  \( [P_0-P_0-P_0] \) denotes the least \( \Pi_0^1 \)-indescribable-\( \Pi_0^1 \)-indescribable-\( \Pi_0^1 \)-indescribable cardinal.

  \( [P_1] \) denotes the least \( \Pi_1^1 \)-indescribable cardinal, which is also the least Weakly Compact Cardinal.

  \( [P_1-P_0] \) denotes the least \( \Pi_1^1 \)-indescribable-\( \Pi_0^1 \)-indescribable cardinal.

  \( [P_1-P_0:P_1] \) denotes the least \( \Pi_1^1 \)-indescribable-\( \Pi_0^1 \)-indescribable and \( \Pi_1^1 \)-indescribable cardinal.

  \( [P_1-P_1] \) denotes the least \( \Pi_1^1 \)-indescribable-\( \Pi_1 \)-indescribable cardinal.

  \( [P_2] \) denotes the least \( \Pi_2^1 \)-indescribable cardinal.

The Similarity to Rathjen's Capital \( \Psi \)

  Stegert's First \( \Psi \) is similar to Rathjen's Capital \( \Psi \). Both OCFs don't monotonically increase in the variable in the brackets (In this case it's the superscript).

  From the definition of Rathjen's Capital \( \Psi \):

  \( \begin{align} \Psi_\alpha^\beta(\gamma)=min(\{\delta| & \delta\in M^\beta\cap\alpha \\ & C(\gamma,\delta)\cap\alpha=\delta \\ & \alpha,\gamma\in C(\gamma,\delta) \}\cup\{\alpha\}) \end{align} \)


  We can define a set \( M_\alpha^\beta(\gamma) \) and mimic the definition of the set \( \mathfrak{M}_\mathbb{X}^\alpha \) as follows:

  \( \Psi_\alpha^\beta(\gamma) \) returns the least element of the set \( M_\alpha^\beta(\gamma) \), which contains ordinals \( \kappa \) satisfying conditions as follows:

  1. \( \kappa<\alpha \).

  2. \( \kappa\in M^\beta \).

  3. \( C(\gamma,\kappa)\cap\alpha=\kappa \).

  4. \( \alpha,\gamma\in C(\gamma,\kappa) \).

  If \( M_\alpha^\beta(\gamma) \) is undefined, then \( \Psi_\alpha^\beta(\gamma) \) returns \( \alpha \).


  Also, the set \( M^\beta \) also has some correspondences with some classes of indescribable cardinals:

  \( M^1 \) corresponds to the class of \( \Pi_0^1 \)-indescribable cardinals.

  \( M^2 \) corresponds to the class of \( \Pi_0^1 \)-indescribable-\( \Pi_0^1 \)-indescribable cardinals.

  \( M^3 \) corresponds to the class of \( \Pi_0^1 \)-indescribable-\( \Pi_0^1 \)-indescribable-\( \Pi_0^1 \)-indescribable cardinals.

  \( \cdots \)


  As a result, Stegert's First \( \Psi \) can be considered as an extension to Rathjen's Capital \( \Psi \), with the quantity of variables varying depending on the uncountable regular cardinal used.

The \( \Pi_0^2 \)-Indescribable Cardinal \( \Xi \)

  The \( \Pi_0^2 \)-Indescribable Cardinal \( \Xi \) is the key to this OCF, which is defined to be the least cardinal that is \( \Pi_n^1 \)-indescribable for all natural numbers \( n \). The idea of this OCF is to collapse (Generate a Reflection Configuration from it, plug in the ordinals, and then plug it into the OCF) this cardinal multiple times to get the designated ordinal. In fact, all the example cardinals displayed in the Indescribable Bracket Notation above can be obtained in this method. Note that we're using a version of cardinals that is based on beth numbers instead of aleph numbers because \( \Pi_0^1 \)-indescribable cardinals are equivalent to Strongly Inaccessible Cardinals. Since the cardinals we use in the OCFs are completely arbitrary, this OCF will work similarly as the previous OCFs. We can also assume the "Generalized Continuum Hypothesis" if we want to eliminate the difference between aleph numbers and beth numbers.


  Stegert's First \( \Psi \) isn't perfect. The paper contained a lot of errors that caused this OCF not to work. For this reason, the version of Stegert's First \( \Psi \) here will have differences from the original paper. All changes from the original paper will be explained here. And in this case, the original version derived from the paper will also be provided.

  The ordinal \( \Psi_{(\omega^+;P_0;\epsilon;\epsilon;0)}^{\varepsilon_{\Xi+1}} \) is called the Small Stegert Ordinal (SSO). It's the upper bound of the PTO of \( KP+\Pi_\omega-reflection \).

The Exclusive Command "ref"

  You can use the command "ref", which is a command exclusively in this ordinal system, in the Calculation Interface. The command "ref ord" displays the complete form of the Reflection Configuration and the \( \vec{R} \) value defined using the ordinal "ord" in computer code. If "ord" is in the form (sC,...) (With C being an ordinal in computer code), which corresponds to the ordinal \( \Psi_\mathbb{X}^\alpha \), it will also display the complete form of the Reflection Instance \( \mathbb{X} \) and the definition of the set \( \mathfrak{M}_\mathbb{X}^\alpha \).


  Example1:

  Input: ref (+(v,(v,)))

  Console:

  \( [{\omega}^{+},]=({\omega}^{+};{P}_{0};\epsilon;\epsilon;0) \)


  \( \vec{R}_{{\omega}^{+}}=({M}_{[\Xi,\cdots]}^{<\omega}-{P}_{0}) \)


  Example2:

  Input: ref (sZ,(v,)(v,),(v,(v,)))

  Console:

  \( [{\mathfrak{p}}_{[\Xi,2]}^{\omega},]=({\mathfrak{p}}_{[\Xi,2]}^{\omega};{P}_{1};({M}_{[\Xi,\cdots]}^{<\omega}-{P}_{0});[\Xi,2];\omega+1) \)


  \( [\Xi,2]=(\Xi;{P}_{2};\epsilon;\epsilon;\omega) \)


  \( \vec{R}_{{\mathfrak{p}}_{[\Xi,2]}^{\omega}}=({M}_{[\Xi,\cdots]}^{<\omega}-{P}_{1},{M}_{[\Xi,\cdots]}^{<\omega}-{P}_{0}) \)


  The set \( \mathfrak{M}_{[\Xi,2]}^{\omega} \) contains ordinals \( \alpha \) that satisfies all the following conditions:

  1. \( \alpha<\Xi \)

  2. \( C(\omega,\alpha)\cap\Xi=\alpha \)

  3. \( [\Xi,2],\omega\in C(\alpha) \)

  2. \( C(\omega+1,\alpha)\cap{\mathfrak{p}}_{[\Xi,1]}^{\omega}=\alpha \)

Ordinal Notation

Notation

  We define \( S^* \) to be the set that contains all the strings composed of the following symbols:

  Constant "\( \overline{0} \)" and "\( \Xi \)",

  Function symbols "\( \varphi \)", "\( ^+ \)", "\( \Psi \)" and "\( v \)",

  And other symbols "\( + \)", "\( ( \)", "\( ) \)" and "\( , \)".


  We also define \( S \) to be the set that contains all the strings in \( S^* \) that doesn't contain "\( v \)", which means \( S \) is a subset of \( S^* \).

  We define the subsets of \( S^* \), \( T_m^* \) and \( T_s^* \) as follows:

  01. \( \overline{0}\in T_m^* \)

  02. \( \Xi\in T_m^* \) and \( \Xi\in T_s^* \)

  03. For all \( a\in T_s^* \) and \( b\in T_m^*\setminus\{\overline{0}\} \), \( a+b\in T_m^* \)

  04. For all \( a,b\in T_m^* \), \( \varphi(a,b)\in T_m^* \) and \( \varphi(a,b)\in T_s^* \)

  05. For all \( a\in T_m^* \), \( a^+\in T_m^* \) and \( a^+\in T_s^* \)

  06. For all \( b,a_0,a_1,a_2,\cdots,a_n\in T_m^* \) with \( n\in\mathbb{N} \), \( \Psi(b,a_1,a_2,\cdots,a_n,a_0)\in T_m^* \) and \( \Psi(b,a_1,a_2,\cdots,a_n,a_0)\in T_s^* \)

  07. For all \( a\in\mathbb{N} \), \( v(a)\in T_m^* \) and \( v(a)\in T_s^* \)


  We also define \( T_m \) and \( T_s \) to be the set that contains all the strings in \( T_m^* \) and \( T_s^* \) respectively that doesn't contain "\( v \)", which means \( T_m \) and \( T_s \) are subsets of \( T_m^* \) and \( T_s^* \) respectively.

  We define \( MP \) to be the set of "M-P-Expression" strings as follows:

  01. \( \epsilon\in MP \)

  02. For all \( a,b,c\in T_m \), \( (M_{[a,\cdots]}^{<b}-P_c)\in MP \)

  03. For all \( A,B\in MP\setminus\{\epsilon\} \), \( AB\in MP \)

  04. For all \( A\in MP \), \( A\epsilon=\epsilon A=A \)


  Throughout this article, we use the following abbreviations:

  01. \( \varphi_a(b):=\varphi(a,b) \)

  02. \( \Psi_{[b,]}^a:=\Psi(b,a) \)

  03. \( \Psi_{[b,a_1,a_2,\cdots,a_n]}^{a_0}:=\Psi(b,a_1,a_2,\cdots,a_n,a_0) \) with \( n\in\mathbb{N} \) and \( n\ge1 \)

  04. \( v_a:=v(a) \)

  05. \( \overline{1}:=\varphi_\overline{0}(\overline{0}) \)

  06. For all \( n\in\mathbb{N} \), \( \overline{n+1}:=\overline{n}+\overline{1} \)

  07. \( \overline{\omega}:=\varphi_\overline{0}(\overline{1}) \)

  08. For all \( (M_0)(M_1)\cdots(M_n)\in MP \) with \( n\in\mathbb{N} \), \( (M_0,M_1,\cdots,M_n):=(M_0)(M_1)\cdots(M_n) \)

  09. \( \exists_m^n x(P(x)):\Leftrightarrow\exists x\in\{k\in\mathbb{N}|m\le k\le n\}(P(x)) \)

  10. \( \forall_m^n x(P(x)):\Leftrightarrow\forall x\in\{k\in\mathbb{N}|m\le k\le n\}(P(x)) \)

Ordering

  We define the binary relation \( < \) as follows:

  \( (a\in T_m,b\in T_m)\mapsto a<b\in\{\mathbb{T},\mathbb{F}\} \)

  01. If \( b=\overline{0} \), return \( \mathbb{F} \)

  02. If \( a=\overline{0}\land b\neq\overline{0} \), return \( \mathbb{T} \)

  03. If \( a=a_0+a_1\land b=b_0+b_1\land a_0,b_0\in T_s\land a_1,b_1\in T_m\setminus\{\overline{0}\} \), then:

  03.01. If \( a_0<b_0 \), return \( \mathbb{T} \)

  03.02. If \( \neg a_0<b_0 \), return \( \neg b_0<a_0\land a_1<b_1 \)

  04. If \( a=a_0+a_1\land b,a_0\in T_s\land a_1\in T_m\setminus\{\overline{0}\} \), return \( a_0<b \)

  05. If \( b=b_0+b_1\land a,b_0\in T_s\land b_1\in T_m\setminus\{\overline{0}\} \), return \( \neg b_0<a \)


  06. If \( a=\Xi\land b=\Xi \), return \( \mathbb{F} \)

  07. If \( a=\varphi_{a_0}(a_1)\land b=\varphi_{b_0}(b_1)\land a_0,a_1,b_0,b_1\in T_m \), then:

  07.01. If \( a_0<b_0 \), return \( a_1<b \)

  07.02. If \( b_0<a_0 \), return \( a<b_1 \)

  07.03. If \( a_0=_*b_0 \), return \( a_1<b_1 \)

  08. If \( a={a_0}^+\land b={b_0}^+\land a_0,b_0\in T_m \), return \( a_0<b_0 \)

  09. If \( a=\Psi_{[a',a_1,a_2,\cdots,a_m]}^{a_0}\land b=\Psi_{[b',b_1,b_2,\cdots,b_n]}^{b_0}\land a',a_0,a_1,a_2,\cdots,a_m,b',b_0,b_1,b_2,\cdots,b_n\in T_m \), then:

  09.01. If \( \neg b<a' \), return \( \mathbb{T} \)

  09.02. Else if \( \neg a_0<b_0\land(\neg b'\in C(a_0,a)\vee\exists_0^n i(\neg b_i\in C(a_0,a))) \), return \( \mathbb{T} \)

  09.03. Else if \( \neg a<b' \), return \( \mathbb{F} \)

  09.04. Else if \( \neg a'\in C(b_0,b)\vee\exists_0^m i(\neg a_i\in C(b_0,b)) \), return \( \mathbb{F} \)

  09.05. Else if \( b_0<a_0 \), return \( \mathbb{F} \)

  09.06. Else if \( a_0<b_0 \), return \( \mathbb{T} \)

  09.07. Else if \( a'<b'\vee b'<a' \), return \( \mathbb{F} \)

  09.08. Loop with \( i=1,2,\cdots,m \):

  09.08.01. If \( a_i<b_i \), return \( a_i\in C(b_i,b) \)

  09.08.02. If \( b_i<a_i \), return \( \neg b_i\in C(a_i,a) \)

  09.09. Else, return \( \mathbb{F} \)


  10. If \( a=\Xi\land b\neq\Xi \), then:

  10.01. If \( b=\varphi_{b_0}(b_1)\land b_0,b_1\in T_m \), return \( (a<b_0\vee b_1\neq\overline{0})\land(\neg b_0<a\vee a<b_1) \)

  10.02. If \( b={b_0}^+\land b_0\in T_m \), return \( a<b_0 \)

  10.03. If \( b=\Psi_{[b',b_1,b_2,\cdots,b_n]}^{b_0}\land b',b_0,b_1,b_2,\cdots,b_n\in T_m \), return \( \mathbb{F} \)

  11. If \( a\neq\Xi\land b=\Xi \), then:

  11.01. If \( a=\varphi_{a_0}(a_1)\land a_0,a_1\in T_m \), return \( a_0<b\land a_1<b \)

  11.02. If \( a={a_0}^+\land a_0\in T_m \), return \( a_0<b \)

  11.03. If \( a=\Psi_{[a',a_1,a_2,\cdots,a_n]}^{a_0}\land a',a_0,a_1,a_2,\cdots,a_n\in T_m \), return \( \mathbb{T} \)


  12. If \( a=\varphi_{a_0}(a_1)\land(b={b_0}^+\vee b=\Psi_{[b',b_1,b_2,\cdots,b_n]}^{b_0})\land a_0,a_1,b',b_0,b_1,b_2,\cdots,b_n\in T_m \), then:

  12.01. Return \( a_0<b\land a_1<b \)

  13. If \( (a={a_0}^+\vee a=\Psi_{[a',a_1,a_2,\cdots,a_n]}^{a_0})\land b=\varphi_{b_0}(b_1)\land a',a_0,a_1,a_2,\cdots,a_n,b_0,b_1\in T_m \), then:

  13.01. Return \( (a<b_0\vee b_1\neq\overline{0})\land(\neg b_0<a\vee a<b_1) \)

  14. If \( a={a_0}^+\land b=\Psi_{[b',b_1,b_2,\cdots,b_n]}^{b_0}\land a_0,b',b_0,b_1,b_2,\cdots,b_n\in T_m \), then:

  14.01. If \( b'={b''}^+\land b''\in T_m \), return \( a<b' \)

  01.02. Let \( c_{Lm}=L(c_m,b_m) \), \( c_{Rm}=R(c_m,b_m) \), \( d_m=Solve(l_m,UB_m(a')) \)

  01.03. Loop with \( i=u,\cdots,2,1,0 \):

  01.03.01. Let \( e_m=\begin{cases} c_m & m\le i \\ d_m & m>i \end{cases} \)

  01.03.02. If \( b=\overline{0}\land\forall_{i+1}^u x(c_{Rx}=\overline{0}) \), then:

  01.03.02.01. Loop with \( j=i,i+1,i+2,\cdots,u \):

  01.03.02.01.01. If \( \overline{1}<Cof(R(e_j,b_j))\land\forall_i^{j-1}x(Cof(e_x)=\overline{1}) \), return \( Cof(e_j) \)

  01.03.03. Else if \( LS_i(a')=0\land c_{Li}\neq\overline{0} \), return \( CPM_i(c_i,a) \)

  01.03.04. Else if \( LS_i(a')\neq0\land c_i\neq\overline{0} \), then:

  01.03.04.01. Loop with \( j=i,i+1,i+2,\cdots,u \):

  01.03.04.01.01. If \( LS_j(a')=0\vee Cof(e_j)\neq\overline{1} \), return \( CPM_j(e_j,a) \)

  01.04. Return \( CP(a',b) \)

  02. Else, return \( \overline{\omega} \)


  We define the main collapsing cofinality function \( CPM \) as follows:

  \( (s\in T,a\in T,k\in\mathbb{N})\mapsto CPM_k(s,a)\in T \)

  01. If \( a=\Psi_{[a',a_1,a_2,\cdots,a_n]}^{a_0}\land a',a_0,a_1,a_2,\cdots,a_n\in T_m \), then:

  01.01. Let \( d=s \)

  01.02. If \( LS_k(a')=0 \), let \( d=L(s,CC_k(a')) \)

  01.03. If \( Cof(d)<CC_k(a') \), return \( Cof(d) \)

  01.04. If \( \neg Cof(d)<CC_k(a') \), return \( \overline{\omega} \)

  02. Else, return \( \overline{\omega} \)


  We also define that \( Cof(\Gamma_{\Xi+1})=\overline{\omega} \).

Fundamental Sequence

  We define the fundamental sequence \( [] \) as follows:

  \( (a\in T,n\in T)\mapsto a[n]\in T \)

  01. If \( a=\overline{0} \), return \( \overline{0} \)

  02. If \( a\neq\overline{0}\land a\in Reg \), return \( n \)

  03. If \( a\neq\overline{0}\land\neg a\in Reg \), then:

  03.01. If \( a=a_0+a_1\land a_0\in T_s\land a_1\in T_m\setminus\{\overline{0}\} \), return \( Add(a_0,a_1[n]) \)

  03.02. If \( a=\varphi_{a_0}(a_1)\land a_0,a_1\in T_m \), then:

  03.02.01. If \( a_1=\overline{0} \), then:

  03.02.01.01. If \( a_0=\overline{0} \), return \( \overline{0} \)

  03.02.01.02. If \( Cof(a_0)=\overline{1} \), then:

  03.02.01.02.01. If \( n=\overline{0} \), return \( \overline{0} \)

  03.02.01.02.02. If \( n\neq\overline{0} \), return \( Norm(\varphi_{a_0[\overline{0}]}(a[n[\overline{0}]])) \)

  03.02.01.03. If \( Cof(a_0)\ge\overline{\omega} \), return \( Norm(\varphi_{a_0[n]}(\overline{0})) \)

  03.02.02. If \( Cof(a_1)=\overline{1} \), then:

  03.02.02.01. If \( a_0=\overline{0} \), then:

  03.02.02.01.01. If \( n=\overline{0} \), return \( \overline{0} \)

  03.02.02.01.02. If \( n\neq\overline{0} \), return \( Add(a[n[\overline{0}]], \varphi_\overline{0}(a_1[\overline{0}])) \)

  03.02.02.02. If \( Cof(a_0)=\overline{1} \), then:

  03.02.02.02.01. If \( n=\overline{0} \), return \( Norm(\varphi_{a_0}(a_1[\overline{0}])) \)

  03.02.02.02.02. If \( n\neq\overline{0}\land n[\overline{0}]=\overline{0} \), return \( \varphi_{a_0[\overline{0}]}(Suc(a[n[\overline{0}]])) \)

  03.02.02.02.03. If \( n[\overline{0}]\neq\overline{0} \), return \( \varphi_{a_0[\overline{0}]}(a[n[\overline{0}]]) \)

  03.02.02.03. If \( Cof(a_0)\ge\overline{\omega} \), return \( \varphi_{a_0[n]}(Suc(Norm(\varphi_{a_0}(a_1[\overline{0}])))) \)

  03.02.03. If \( Cof(a_1)\ge\overline{\omega} \), return \( Norm(\varphi_{a_0}(a_1[n])) \)

  03.03. If \( a=\Psi_{[a',a_1,a_2,\cdots,a_n]}^{a_0}\land a',a_0,a_1,a_2,\cdots,a_n\in T_m \), return \( P(a,IT(a))[n] \)


  We define the initial term \( IT \) as follows:

  \( (a\in T)\mapsto IT(a)\in T \)

  01. If \( a=\overline{0} \), return \( \overline{0} \)

  02. If \( a=\Xi \), return \( \overline{\omega} \)

  03. If \( a=a_0+a_1\land a_0\in T_s\land a_1\in T_m\setminus\{\overline{0}\} \), return \( \overline{0} \)

  04. If \( a=\varphi_{a_0}(a_1)\land a_0,a_1\in T_m \), return \( \overline{0} \)

  05. If \( a={a_0}^+\land a_0\in T_m \), then:

  05.01. If \( a_0=\overline{\omega} \), return \( \overline{0} \)

  05.02. If \( a_0\neq\overline{\omega} \), return \( a_0 \)

  06. If \( a=\Psi_{[a',a_1,a_2,\cdots,a_n]}^{a_0}\land a',a_0,a_1,a_2,\cdots,a_n\in T_m \), then:

  06.01. Let \( u=R_v(a') \), \( l_m=LB_m(a') \), \( b_m=CC_m(a') \), \( c_m=Solve(l_m,a_m) \)

  06.02. Let \( c_{Lm}=L(c_m,b_m) \), \( c_{Rm}=R(c_m,b_m) \), \( d_m=Solve(l_m,UB_m(a')) \)

  06.03. Loop with \( i=u,\cdots,2,1,0 \):

  06.03.01. If \( Cof(c_{Ri})=\overline{1} \), then:

  06.03.01.01. Let \( r=RP_i(a,c_i[\overline{0}]) \)

  06.03.01.02. Loop with \( j=i,i+1,i+2,\cdots,u \):

  06.03.01.02.01. If \( \neg Cof(d_j)<b_j \), return \( r \)

  06.03.01.02.02. If \( \overline{1}<Cof(d_j) \), return \( \overline{0} \)

  06.03.01.02.03. Let \( r=RP_j(c,d_j[\overline{0}]) \)

  06.03.01.03. Return \( r \)

  06.03.02. Else if \( c_{Ri}\neq\overline{0} \), then:

  06.03.02.01. If \( FP_i(a) \), return \( t(c_m,b_m) \)

  06.03.02.02. If \( \neg FP_i(a) \), return \( \overline{0} \)

  06.03.03. Else if \( c_{Li}\neq\overline{0} \), then:

  06.03.03.01. If \( Cof(c_{Li})<b_i\land FP_i(a) \), return \( t(c_m,b_m) \)

  06.03.03.02. If \( \neg FP_i(a) \), return \( \overline{0} \)

  06.04. Return \( IT(a') \)


  We define the collapsing fundamental sequence \( P[] \) as follows:

  \( (a\in T,b\in T,n\in T)\mapsto P(a,b)[n]\in T \)

  01. If \( a=\overline{0} \), return \( \overline{0} \)

  02. If \( a=\Xi \), return \( LimCard(b)[n] \)

  03. If \( a=a_0+a_1\land a_0\in T_s\land a_1\in T_m\setminus\{\overline{0}\} \), return \( \overline{0} \)

  04. If \( a=\varphi_{a_0}(a_1)\land a_0,a_1\in T_m \), return \( \overline{0} \)

  05. If \( a={a_0}^+\land a_0\in T_m \), return \( \Gamma(b)[n] \)

  06. If \( a=\Psi_{[a',a_1,a_2,\cdots,a_n]}^{a_0}\land a',a_0,a_1,a_2,\cdots,a_n\in T_m \), then:

  06.01. Let \( u=R_v(a') \), \( l_m=LB_m(a') \), \( b_m=CC_m(a') \), \( c_m=Solve(l_m,a_m) \)

  06.02. Let \( c_{Lm}=L(c_m,b_m) \), \( c_{Rm}=R(c_m,b_m) \), \( d_m=Solve(l_m,UB_m(a')) \)

  06.03. Loop with \( i=u,\cdots,2,1,0 \):

  06.03.01. Let \( e_m=\begin{cases} c_m & m\le i \\ d_m & m>i \end{cases} \)

  06.03.02. If \( b=\overline{0}\land\forall_{i+1}^u x(c_{Rx}=\overline{0}) \), then:

  06.03.02.01. Loop with \( j=i,i+1,i+2,\cdots,u \):

  06.03.02.01.01. If \( \overline{1}<Cof(R(e_j,b_j))\land\forall_i^{j-1}x(Cof(e_x)=\overline{1}) \), then:

  06.03.02.01.01.01. Let \( r=RP_j(a,e_j[n]) \)

  06.03.02.01.01.02. Loop with \( k=i,i+1,i+2,\cdots,j-1 \):

  06.03.02.01.01.02.01. Let \( r=RP_k(r,e_k[\overline{0}]) \):

  06.03.02.01.01.03. Return \( r \)

  06.03.03. Else if \( LS_i(a')=0\land c_{Li}\neq\overline{0} \), return \( PM_i(c_i,a,b,a)[n] \)

  06.03.04. Else if \( LS_i(a')\neq0\land c_i\neq\overline{0} \), then:

  06.03.04.01. Let \( r=a \)

  06.03.04.02. Loop with \( j=i+1,i+2,i+3,\cdots,u \):

  06.03.04.02.01. Let \( r=RP_j(r,\overline{0}) \)

  06.03.04.03. Loop with \( j=i,i+1,i+2,\cdots,u \):

  06.03.04.03.01. If \( LS_j(a')=0\vee Cof(e_j)\neq\overline{1} \), return \( PM_j(e_j,a,b,r)[n] \)

  06.03.04.03.02. Let \( r=RP_j(r,e_j[\overline{0}]) \)

  06.04. Return \( P(a',b)[n] \)


  We define the strongly critical sequence \( \Gamma[] \) as follows:

  \( (a\in T,n\in T)\mapsto \Gamma(a)[n]\in T \)

  01. If \( n=\overline{0} \), return \( a \)

  02. If \( n\neq\overline{0} \), then:

  02.01. If \( \varphi_{\Gamma(a)[n[\overline{0}]]}(\overline{0})\in T \), return \( \varphi_{\Gamma(a)[n[\overline{0}]]}(\overline{0}) \)

  02.02. If \( \neg\varphi_{\Gamma(a)[n[\overline{0}]]}(\overline{0})\in T \), return \( \varphi_{\Gamma(a)[n[\overline{0}]]}(\overline{1}) \)


  We define the limit cardinal sequence \( LimCard[] \) as follows:

  \( (a\in T,n\in T)\mapsto LimCard(a)[n]\in T \)

  01. If \( n=\overline{0} \), return \( a \)

  02. If \( n\neq\overline{0} \), return \( {LimCard(a)[n[\overline{0}]]}^+ \)


  We define the main collapsing fundamental sequence \( PM[] \) as follows:

  \( (s\in T,a\in T,b\in T,c\in T,n\in T,k\in\mathbb{N})\mapsto PM_k(s,a,b,c)[n]\in T \)

  01. If \( a=\Psi_{[a',a_1,a_2,\cdots,a_n]}^{a_0}\land a',a_0,a_1,a_2,\cdots,a_n\in T_m \), then:

  01.01. Let \( d=s \)

  01.02. If \( LS_k(a')=0 \), let \( d=L(s,CC_k(a')) \)

  01.03. If \( Cof(d)<CC_k(a') \), then:

  01.03.01. If \( LS_k(a')=0 \), return \( RP_k(c,Add(d[n],b)) \)

  01.03.02. If \( LS_k(a')\neq0 \), return \( RP_k(RP_{LS_k(a')}(c,b),Add(d[n],b)) \)

  01.04. If \( CC_k(a')<Cof(d) \), then:

  01.04.01. If \( n=\overline{0} \), return \( b \)

  01.04.02. If \( n\neq\overline{0} \), return \( RP_k(c,Add(Re(d,CC_k(a'))[n[\overline{0}]],b)) \)

  01.05. If \( \neg Cof(d)<CC_k(a')\land\neg CC_k(a')<Cof(d) \), then:

  01.05.01. If \( n=\overline{0} \), return \( b \)

  01.05.02. If \( n\neq\overline{0} \), return \( RP_k(c,d[P(a,b)[n[\overline{0}]]]) \)

  02. Else, return \( \overline{0} \)


  We define the recursive sequence \( Re[] \) as follows:

  \( (a\in T,b\in T,n\in T)\mapsto Re(a,b)[n]\in T \)

  01. If \( n=\overline{0} \), return \( a[b] \)

  02. If \( n\neq\overline{0} \), then:

  02.01. Let \( c=Cof(a) \), \( l=LB_0(c) \), \( p=Re(a,b)[n[\overline{0}]] \)

  02.02. If \( a<l \), return \( a[RP_0(LC(c),p)] \)

  02.03. If \( \neg a<l \), return \( a[RP_0(LC(c),Solve(l,p))] \)


  We define the strong fundamental sequence \( {[]}^* \) in case we want an ordinal of uncountable cofinality to expand as a smaller ordinal with countable cofinality:

  \( (a\in T,n\in T)\mapsto a{[n]}^*\in T \)

  01. If \( \neg\overline{\omega}<Cof(a) \), return \( a[n] \)

  02. If \( \overline{\omega}<Cof(a)\land n=\overline{0} \), return \( a[LC(a)] \)

  03. If \( \overline{\omega}<Cof(a)\land n\neq\overline{0} \), return \( a[RP_0(LC(a),\Gamma(\Xi)[n[\overline{0}]])] \)

  \( (n\in T)\mapsto\Gamma_{\Xi+1}[n]\in T \)

  Return \( \Gamma(\Xi)[n] \)
